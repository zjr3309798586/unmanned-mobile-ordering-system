# 云豹小点项目验收清单

本文档用于提交前自查,重点验证项目是否能按真实业务流程运行。

## 1. 前台用户流程

1. 打开 `http://127.0.0.1:8080/`,确认首页能正常加载 Banner、热门商品和底部导航。
2. 进入点餐页,点击商品加号,确认商品加入购物车且页面仍停留在点餐页。
3. 点击购物车区域,确认已选商品抽屉能打开,数量加减能同步更新金额。
4. 进入购物车结算页,确认商品清单、优惠券、总价、优惠金额、实付金额显示正确。
5. 点击提交订单,确认订单创建成功并跳转到订单页。
6. 在订单页确认新订单能显示,状态为待取餐或对应业务状态。

## 2. 省钱卡和优惠券流程

1. 未开通省钱卡时,专属优惠券应显示开通后可领取。
2. 开通省钱卡后,优惠券按钮应变为立即领取。
3. 领取优惠券后,购物车结算页能看到可用券。
4. 未达到满减门槛时,优惠券不能被使用。
5. 达到门槛时,优惠金额和实付金额应正确计算。

## 3. 后台管理流程

1. 打开 `http://127.0.0.1:8080/admin/login.html`,使用管理员账号登录。
2. 数据看板应能显示营业额、订单总数、在售商品和购物车商品数。
3. 商品管理应支持新增、编辑、下架商品,并支持填写或上传商品图片。
4. 活动管理应支持新增、编辑、停用 Banner,并支持填写或上传 Banner 图片。
5. 优惠券管理应支持新增、编辑、停用优惠券。
6. 订单管理应显示订单运营概览,并支持完成或取消待取餐订单。

## 4. 后端接口流程

1. `GET /api/health` 返回正常。
2. `GET /api/products` 返回商品列表。
3. `POST /api/auth/dev-login` 能创建游客会话。
4. 登录后 `POST /api/cart/items` 能加入购物车。
5. 登录后 `GET /api/cart` 能查询购物车。
6. 登录后 `POST /api/orders` 能创建订单。
7. 管理员登录后 `GET /api/admin/orders` 能看到前台订单。

## 5. 提交前检查

1. 执行 `mvn test`,确认后端测试通过。
2. 对 H5 和小程序脚本执行语法检查。
3. 执行 `git status --short`,确认要提交的文件符合本次改动范围。
4. 确认页面和文档中不再把结算流程写成独立页面。
