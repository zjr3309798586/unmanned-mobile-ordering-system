# 云豹小点界面设计学习笔记

本文档用于指导“云豹小点”无人移动点餐系统的前台 H5、微信小程序和后台管理页面设计。重点不是照搬古茗、喜茶、瑞幸的界面，而是学习它们的设计规律，再落到自己的项目里。

## 1. 先明确项目气质

云豹小点现在更适合走“蓝白清爽 + 轻量科技感 + 点餐效率高”的方向。

原因：

- 项目名是“无人移动点餐系统”，有一定智能化、移动化特点。
- 吉祥物是蓝白云豹，天然适合蓝白品牌色。
- 前台用户端需要让用户快速完成点餐，不适合过度复杂。
- 后台管理端要让管理员看数据、管商品，应该简洁、清楚、专业。

推荐关键词：

```text
清爽
干净
可信
年轻
高效
圆角卡片
蓝白主色
轻量渐变
真实奶茶店小程序感
```

不推荐关键词：

```text
花哨
复杂
黑金
大面积紫色
过度拟物
像模板站
像 AI 随机生成
```

## 2. 参考对象应该怎么学

### 2.1 瑞幸：学“商业效率”

瑞幸的核心特点不是装饰多，而是非常明确地推动用户下单。

可以学习：

- 大面积品牌主色，让用户一眼记住蓝色。
- 首页重点突出优惠、活动和点单入口。
- 商品列表清晰，价格和加购按钮非常醒目。
- 点餐页左侧分类、右侧商品的结构简单直接。
- 会员卡、省钱卡、优惠券都围绕“省钱”和“复购”展开。

不要照搬：

- 瑞幸 Logo。
- 瑞幸具体文案。
- 瑞幸商品图。
- 瑞幸自由卡、瑞王卡等命名。

适合云豹小点的转化：

```text
瑞幸蓝 -> 云豹蓝
瑞幸自由卡 -> 云豹省钱卡
瑞幸新人券 -> 新人专享券
瑞幸咖啡商品 -> 奶茶、果茶、咖啡、轻食
```

### 2.2 喜茶：学“品质感和留白”

喜茶的界面通常更注重质感、留白和品牌调性。

可以学习：

- 页面不要塞太满，卡片之间留足间距。
- Banner 图要有主视觉，不要只堆文字。
- 商品详情页要突出图片、标题、价格、规格选择。
- 点单页可以加入门店制作状态、预计取餐时间等信息，让用户有掌控感。

不要照搬：

- 喜茶黑白极简品牌调性。
- 喜茶具体产品名称和视觉素材。
- 喜茶官方插画。

适合云豹小点的转化：

```text
留白感 -> 页面更干净
制作进度提示 -> 当前门店制作中 12 杯，预计 8 分钟取餐
商品详情质感 -> 大图 + 简短描述 + 规格卡片
```

### 2.3 古茗：学“茶饮活动氛围”

古茗更偏茶饮连锁，活动入口和会员权益比较接近本项目。

可以学习：

- 首页放活动 Banner。
- 新人券包、会员权益、集点活动可以卡片化。
- 商品更偏水果茶、奶茶、轻饮。
- 视觉可以更温暖、更有生活感。

不要照搬：

- 古茗品牌字样。
- 古茗绿色系统。
- 古茗产品图和 IP 形象。

适合云豹小点的转化：

```text
新人券包
集杯任务
省钱卡专属券
当季新品
门店公告
```

## 3. 云豹小点推荐设计规范

### 3.1 主色

建议使用蓝白系统，不要再混太多暖橙。

```css
:root {
  --brand-blue: #1f6fff;
  --brand-deep: #0b2f6b;
  --brand-light: #eaf3ff;
  --bg: #f5f8fc;
  --card: #ffffff;
  --text: #102033;
  --muted: #7a8aa0;
  --line: #e6edf5;
  --danger: #ff5b5b;
  --price: #ff6b2c;
}
```

用法：

- 主按钮、加购按钮、底部导航激活态：`--brand-blue`
- 标题、重要文字：`--text`
- 背景：`--bg`
- 卡片背景：`--card`
- 价格：`--price`
- 删除、取消：`--danger`

### 3.2 圆角

移动端餐饮页面应该大量使用圆角卡片。

推荐：

```text
普通卡片：16px
大 Banner：22px
按钮：999px 或 14px
商品图片：14px
底部弹层：24px 24px 0 0
```

### 3.3 阴影

阴影要轻，不要像悬浮广告。

推荐：

```css
box-shadow: 0 10px 30px rgba(31, 111, 255, 0.08);
```

不要用：

```css
box-shadow: 0 20px 60px rgba(0, 0, 0, 0.35);
```

后者会显得很重，不像清爽小程序。

### 3.4 字体层级

移动端页面不要所有字一样大。

推荐：

```text
页面大标题：22px - 26px
模块标题：17px - 19px
商品标题：15px - 16px
正文说明：13px - 14px
辅助文字：11px - 12px
价格：18px - 24px
```

### 3.5 间距

页面高级感主要来自留白。

推荐：

```text
页面左右边距：14px - 16px
卡片内边距：14px - 18px
模块上下间距：14px - 20px
商品列表间距：10px - 14px
底部导航上方预留：80px - 100px
```

如果页面显得“廉价”，通常不是颜色问题，而是元素太挤、对齐不统一。

## 4. 首页应该怎么设计

首页目标：让用户快速知道“在哪个门店、有什么活动、怎么开始点单”。

推荐结构：

```text
顶部状态区
门店名称 + 距离/营业状态
搜索框
大 Banner
自取/外送双入口
快捷功能入口
热门推荐
新人券/集杯任务
门店公告
底部导航
```

设计重点：

- Banner 要放在靠前位置，但不要占满半屏。
- 自取/外送入口要足够醒目，因为这是点餐前的关键选择。
- 热门推荐商品图片要大，价格要醒目。
- 底部导航固定，当前页面高亮。

首页 Banner 建议：

```text
高度：150px - 190px
圆角：22px
背景：蓝色渐变
内容：云豹小点 + 新品/优惠 + 一键点餐按钮
右侧：云豹简化插画或饮品图
```

## 5. 点餐页应该怎么设计

点餐页目标：让用户快速找到商品并加入购物车。

推荐结构：

```text
顶部门店信息
搜索框
取餐方式/预计时间提示
左侧分类栏
右侧商品列表
商品加购按钮
底部购物车结算栏
底部导航
```

左侧分类：

- 宽度控制在 82px - 96px。
- 当前分类使用蓝色文字 + 浅蓝背景。
- 分类不要太花，只要清楚。

右侧商品卡：

```text
商品图：72px - 88px
商品名：15px - 16px 加粗
描述：12px - 13px 灰色
价格：橙色或红橙色
加号按钮：蓝色圆形
```

底部购物车：

- 未选择商品时显示“请先选择商品”。
- 已选择后显示数量、金额、去结算。
- 点击购物车区域弹出已选商品列表。

这个交互比直接跳购物车更像真实点餐小程序。

## 6. 商品详情页应该怎么设计

商品详情页目标：让用户完成规格选择。

推荐结构：

```text
顶部商品大图
商品名称
商品描述
价格
温度选择
甜度选择
加料选择
数量加减
底部加入购物车 / 立即购买
```

设计重点：

- 商品图要足够大，占据第一视觉。
- 规格选择使用胶囊按钮。
- 当前选中态使用蓝底白字或浅蓝背景 + 蓝字。
- 底部按钮固定，方便操作。

## 7. 省钱卡页应该怎么设计

省钱卡页目标：让用户觉得“开通后能省钱”。

参考瑞幸会员卡类页面，但不要照搬名称。

推荐结构：

```text
蓝色会员卡头图
预计可省金额
开通按钮
专属优惠券列表
省钱价商品
会员权益说明
常见问题
```

设计重点：

- 顶部要像一张真实会员卡。
- 开通按钮要醒目。
- 优惠券必须显示门槛，例如“满 20 可用”。
- 未开通时显示“开通后可领取”。
- 已开通后显示“立即领取”。

## 8. 我的页应该怎么设计

我的页目标：展示用户身份、资产和服务入口。

推荐结构：

```text
用户信息卡
登录/注册入口
会员等级/省钱卡状态
我的资产：优惠券、积分、余额
我的订单入口
更多服务：地址、客服、设置、关于
```

设计重点：

- 没登录时显示“游客用户”或“立即登录”。
- 登录卡片可以使用云豹头像。
- 资产区用 3 到 4 个等宽小格。
- 服务入口要简洁，不要堆太多。

## 9. 后台管理页应该怎么设计

后台管理端目标：让管理员快速找到功能和数据。

推荐结构：

```text
左侧导航
顶部栏
数据概览卡片
核心表格
新增/编辑弹窗
筛选区
```

后台不要像前台一样可爱，应该更专业。

建议：

- 主色仍然用蓝白。
- 大面积白色卡片。
- 表格清楚，按钮少而明确。
- 右上角管理员头像用云豹 Logo 简化版或字母 J。
- 不要写“演示数据”“AI 生成”等字样。

## 10. 图片应该怎么做

### 10.1 商品图

商品图不要乱用真实品牌图。可以用统一风格的插画或简洁 SVG。

推荐风格：

```text
白底
轻阴影
蓝色/浅灰背景
杯子主体突出
水果元素点缀
统一角度
统一光感
```

### 10.2 Banner 图

Banner 不一定要复杂。

一个好 Banner 通常包含：

```text
主标题
副标题
主按钮
主视觉图
背景渐变
少量装饰元素
```

示例文案：

```text
云豹小点
今日新品上新
下单立享新人券
```

### 10.3 吉祥物

云豹头像已经适合做品牌识别。

可以继续做：

- App 图标。
- 我的页头像。
- 空状态插画。
- 底部导航简化图标。
- Banner 角落装饰。

不要每个地方都放很大的吉祥物，否则会显得幼稚。

## 11. AI 生图提示词怎么写

### 11.1 商品图提示词模板

```text
为一个名为“云豹小点”的奶茶点餐小程序生成一张商品图。
画面主体是一杯[饮品名称]，白色透明塑料杯，杯身有简洁蓝色云豹图标。
背景为浅蓝白渐变，干净留白，轻微阴影，电商商品图风格。
不要出现任何真实品牌名称，不要出现古茗、喜茶、瑞幸、蜜雪冰城等字样。
构图居中，适合移动端商品卡片，正方形比例。
```

替换示例：

```text
[饮品名称] = 芝士葡萄冰茶
[饮品名称] = 生椰拿铁
[饮品名称] = 茉莉奶绿
[饮品名称] = 满杯橙香茶
```

### 11.2 首页 Banner 提示词模板

```text
为“云豹小点”奶茶点餐小程序生成首页 Banner。
蓝白清爽风格，现代移动端 UI 视觉。
画面左侧留出文字空间，右侧是一杯奶茶和云豹吉祥物简化形象。
背景为浅蓝到白色渐变，有柔和光斑和圆形装饰。
不要出现真实品牌 Logo，不要出现古茗、喜茶、瑞幸、蜜雪冰城等字样。
画面干净，有高级感，适合 430px 宽手机页面顶部 Banner。
横向比例 16:9。
```

### 11.3 空状态插画提示词模板

```text
为“云豹小点”点餐小程序生成一个空状态插画。
一只简洁可爱的蓝白云豹坐在小桌旁，桌上有一杯奶茶。
整体风格扁平插画，线条干净，颜色为蓝色、白色、浅灰。
不要文字，不要真实品牌标志，适合购物车为空页面。
正方形比例，背景透明或浅蓝白背景。
```

## 12. 改页面时的检查清单

每改完一个页面，都按这个清单看：

```text
页面是否一眼能看出主操作？
颜色是否统一为蓝白体系？
按钮是否足够醒目？
卡片圆角是否统一？
间距是否足够？
商品价格是否清楚？
底部导航是否固定？
当前页面是否高亮？
有没有真实品牌字样？
有没有“演示”“AI”等不该出现的词？
手机 430px 宽度下是否正常？
```

## 13. 最适合你当前项目的改版顺序

不要一次性乱改全部页面。推荐顺序：

```text
1. 首页
2. 点餐页
3. 商品详情页
4. 购物车和提交订单页
5. 省钱卡页
6. 我的页
7. 后台管理页
8. 小程序同步适配
```

原因：

- 首页决定第一印象。
- 点餐页决定真实使用体验。
- 详情页和购物车决定下单闭环。
- 省钱卡和我的页是加分项。
- 后台管理页要最后统一风格。

## 14. 一句话设计原则

```text
云豹小点不是要像某一个品牌，而是要像一个真实可用的茶饮点餐系统。
```

你可以参考瑞幸的效率、喜茶的质感、古茗的茶饮氛围，但最终要统一成自己的蓝白云豹品牌。
